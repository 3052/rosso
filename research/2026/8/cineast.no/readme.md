Cineast (cineast.no) — Norway's free library film streaming service — cannot be
used from the US because login requires a Norwegian national library card
(nasjonalt lånekort). Creating that card requires either: (a) online
registration via ID-porten, which needs a Norwegian national ID number
(fødselsnummer/D-nummer) and BankID/MinID — none available to US residents; or
(b) an in-person visit to a library in Norway, which for people without a
Norwegian ID number only yields a local card that does not work with Cineast.
Unlike some other services, Cineast itself is not geo-blocked ("kan sees hvor
som helst døgnet rundt") — the sole barrier is the library card.
